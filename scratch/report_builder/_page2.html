Project Scope

The Hospital Management System (HMS) is a full-stack clinical and hospital operations platform engineered with Next.js 15 (App Router), React 19, TypeScript, Prisma ORM, and Neon Serverless PostgreSQL. It replaces fragmented manual registers with three integrated worklets: Worklet 1 (Patient & User Management), Worklet 2 (Appointment Scheduling & Electronic Health Records), and Worklet 3 (Billing, Reports & System Administration), serving ADMIN, DOCTOR, RECEPTIONIST, and PATIENT roles across 16 pages, 11 Server Action modules, 1 health API route (GET /api/health), and a 14-model PostgreSQL schema.

Key Objectives
  • Role-Based Security & Access Control: Enforce HS256 JWT authentication via HTTP-only cookies (hms_auth_token), Edge Middleware route guards (src/middleware.ts), and PostgreSQL-verified session healing (requireAuth(), requireRole()).
  • Conflict-Free Concurrent Scheduling: Prevent double-booking under simultaneous requests using a three-layer architecture: linked-list FIFO queue serialization (AppointmentRequestQueue), Prisma interactive transactions (prisma.$transaction), and the PostgreSQL partial unique index unique_active_appointment_slot.
  • Dynamic Availability & Leave Awareness: Compute 30-minute slots from DoctorSchedule shift timings while excluding breaks (breakStartTime–breakEndTime), active DoctorLeave intervals, and existing non-cancelled appointments.
  • Automated Consultation-to-Billing Workflow: Atomically save digital Prescription records, transition visits to COMPLETED, and generate itemized Indian Rupee (₹) bills with 5% GST and multi-channel payment tracking via BillingRequestQueue.
  • Auditability, Analytics & Recovery: Maintain immutable AuditLog trails, provide 14-day revenue/footfall analytics with CSV export, and support JSON database backup/restore scripts.
Scope

The system is scoped to outpatient clinics, polyclinics, and multi-specialty consultation centers requiring centralized patient registration, specialist directory and schedule management, conflict-free appointment booking, longitudinal medical history timelines, automated invoicing, and administrative oversight. Academically, the project demonstrates applied Engineering Design and Innovation (EDI) integration across Basic Programming, Object-Oriented Programming, Data Structures, Database Management Systems, Computer Networks, Operating Systems, Software Engineering, and Web Technology.
