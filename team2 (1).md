## Hospital Management System

## Team-wise Work Assignment Document

## Project Title

Hospital Management System

## Problem Statement

Design and develop a Hospital Management System to automate patient registration, doctor management, appointment scheduling, billing, and medical report management using secure web services, database-driven operations, role-based access control, concurrent appointment scheduling, and scalable system architecture.

## Common Responsibilities (All Teams)

Before beginning development, all teams must jointly finalize:

- Software Requirement Specification (SRS)

- ER Diagram

- Database Schema

- Table Names and Primary Keys

- Coding Standards

- Folder Structure

- Naming Conventions

- API/Function Interfaces

- Git Repository Structure (if applicable)

- System Architecture

- UI Wireframes

- Integration Strategy
